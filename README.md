# Inventario App

Aplicación web para gestionar el inventario de productos. 
Permite agregar, editar, eliminar y clasificar productos según su estado.

## Tecnologías usadas

- React
- Bootstrap 5
- JavaScript
- Node.js

## ¿Cómo correr el proyecto?

1. Clonar el repositorio
2. Instalar dependencias con `npm install`
3. Correr con `npm start`
4. Abrir en el navegador: `http://localhost:3000`

## Funcionalidades

- Agregar productos con nombre, categoría, precio y stock
- Editar y eliminar productos
- Clasificar productos en: Disponible, Bajo Stock y Agotado
- Panel con estadísticas de inventario
